Build Configuration Summary
---------------------------

This build is intended to avoid GPL and nonfree FFmpeg configuration:

- no --enable-gpl
- no --enable-nonfree
- no libx264 or libx265
- native zlib enabled
- libmp3lame enabled
- most encoders, decoders, filters, input devices, output devices, hardware
  accelerators, and postproc disabled
- selected audio encoders, decoders, and audio format/resample filters enabled
  for browser-compatible extraction and preview

See the repository Dockerfile and COMMERCIAL_REMUX_BUILD.md for the exact
configure flags and dependency build steps used for a given release.
